# My Routine PWA

GitHub Pages-ready PWA for the My Routine visualizer.

## GitHub Pages
1. Upload all files in this repository root.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Open the generated HTTPS GitHub Pages URL.

The PWA uses a minimal `manifest.json`, root-level PNG icons, and a service worker.
